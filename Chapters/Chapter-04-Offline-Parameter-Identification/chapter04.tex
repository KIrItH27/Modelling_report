\chapter{Offline Parameter Identification Methods}
\label{chap:offline_identification}

The experimental characterization protocols established in Chapter 3 yield vast, high-resolution datasets comprising terminal voltage, applied current, and surface temperature. However, these raw time-series arrays do not inherently provide the internal parameters of the battery model. Transforming this empirical data into the parameter vector $\theta$ requires the application of system identification theory. This chapter explores the methodologies used to mathematically extract these parameters offline. The term ``offline'' denotes that the estimation algorithms process the entire historical dataset simultaneously (batch processing) with no strict real-time execution constraints, allowing for highly complex, globally optimal matrix inversions and iterative searches that would exceed the computational capacity of an embedded microcontroller.

\section{Curve Fitting and Regression}
\label{sec:curve_fitting_regression}

At its core, the offline identification of battery parameters is an inverse problem. We possess the measured output $Y$ (terminal voltage) generated by a known input sequence $U$ (current) acting on a physical system. Our objective is to determine the optimal set of model parameters $\hat{\theta}$ that minimizes the discrepancy between the measured physical output and the mathematical model's predicted output. This process is broadly categorized into linear regression, utilized for models that can be algebraically transformed into difference equations, and nonlinear curve fitting, required for multi-exponential time-domain responses.

\subsection{Formulation of the Objective Function}
\label{subsec:objective_function}

Regardless of the specific optimization algorithm deployed, regression fundamentally requires the definition of a scalar cost function (or objective function), $J(\theta)$, which quantifies the goodness-of-fit. Let the measured terminal voltage at discrete time step $k$ be $y_k$, and the model's predicted voltage be $\hat{y}_k(\theta)$. The prediction error, or residual, is defined as:
\begin{equation}
\label{eq:residual_def}
e_k(\theta) = y_k - \hat{y}_k(\theta)
\end{equation}

In standard curve fitting, the objective is to minimize the sum of squared residuals (SSR) over the entire dataset of $N$ samples. This Least Squares (LS) formulation is mathematically expressed as:
\begin{equation}
\label{eq:least_squares_cost}
J(\theta) = \frac{1}{2} \sum_{k=1}^{N} e_k^2(\theta) = \frac{1}{2} E(\theta)^T E(\theta)
\end{equation}
where $E(\theta) = [e_1(\theta), e_2(\theta), \dots, e_N(\theta)]^T$ is the residual vector. The factor of $1/2$ is conventionally included to simplify the calculus during analytical differentiation. The optimal parameter vector $\hat{\theta}$ is the argument that globally minimizes this cost function:
\begin{equation}
\label{eq:argmin_ls}
\hat{\theta} = \arg\min_{\theta} J(\theta)
\end{equation}

The mathematical structure of $\hat{y}_k(\theta)$ strictly dictates whether Equation \eqref{eq:argmin_ls} can be solved via a closed-form linear algebra operation or if it requires an iterative, nonlinear numerical solver.

\subsection{Linear Regression via Auto-Regressive Exogenous (ARX) Formulation}
\label{subsec:arx_formulation}

While Equivalent Circuit Models (ECMs) represent physical components (resistors and capacitors), their continuous-time differential equations can be mapped into discrete-time linear difference equations. This transformation allows for the application of standard linear algebra to extract the parameters instantly, bypassing the need for iterative solvers. The most robust method for this is the Auto-Regressive with Exogenous Input (ARX) modeling framework \cite{ljung1999system}.

\subsubsection{Discretization of the First-Order Thevenin Model}
To demonstrate the ARX formulation, consider the first-order Thevenin ECM derived in Chapter 2. The continuous-time transfer function mapping the input current $I(s)$ to the polarization voltage $U_p(s)$ is:
\begin{equation}
\label{eq:thevenin_tf_cont}
H_p(s) = \frac{U_p(s)}{I(s)} = \frac{R_1}{1 + s R_1 C_1} = \frac{R_1}{1 + s\tau_1}
\end{equation}

To implement linear regression, this continuous transfer function must be mapped to the discrete z-domain. Utilizing the bilinear transform (Tustin's approximation), where $s \approx \frac{2}{\Delta t} \frac{1 - z^{-1}}{1 + z^{-1}}$, the discrete transfer function $H_p(z^{-1})$ becomes:
\begin{equation}
\label{eq:thevenin_tf_disc}
H_p(z^{-1}) = \frac{b_0 + b_1 z^{-1}}{1 + a_1 z^{-1}}
\end{equation}
where the discrete coefficients $a_1, b_0,$ and $b_1$ are algebraic combinations of the continuous parameters $R_1$, $C_1$, and the sampling time $\Delta t$.

The total terminal voltage equation in the discrete domain is $V_t(z) = V_{\mathrm{oc}}(z) - U_p(z) - R_0 I(z)$. Rearranging to isolate the dynamic overpotential yields the observable output $y(z) = V_{\mathrm{oc}}(z) - V_t(z)$. Substituting $U_p(z) = H_p(z^{-1}) I(z) + R_0 I(z)$ yields the full system transfer function:
\begin{equation}
\label{eq:full_arx_tf}
y(z) = \left( R_0 + \frac{b_0 + b_1 z^{-1}}{1 + a_1 z^{-1}} \right) I(z)
\end{equation}

Multiplying through by the denominator $(1 + a_1 z^{-1})$ and taking the inverse z-transform yields the time-domain linear difference equation:
\begin{equation}
\label{eq:arx_difference}
y_k = -a_1 y_{k-1} + (R_0 + b_0) i_k + (R_0 a_1 + b_1) i_{k-1}
\end{equation}

\subsubsection{Constructing the Regressor Matrix}
Equation \eqref{eq:arx_difference} is strictly linear with respect to a new set of lumped mathematical coefficients. Let us define a discrete parameter vector $\Theta_{\mathrm{ARX}}$:
\begin{equation}
\label{eq:theta_arx}
\Theta_{\mathrm{ARX}} = [\theta_1, \theta_2, \theta_3]^T = [-a_1, (R_0 + b_0), (R_0 a_1 + b_1)]^T
\end{equation}

The difference equation for a single time step $k$ can now be written as a vector dot product:
\begin{equation}
\label{eq:arx_dot_product}
y_k = \phi_k^T \Theta_{\mathrm{ARX}}
\end{equation}
where $\phi_k = [y_{k-1}, i_k, i_{k-1}]^T$ is the regressor vector at step $k$, containing exclusively known, measured historical data.

For an entire offline dataset containing $N$ samples (e.g., a complete HPPC pulse profile), we stack Equation \eqref{eq:arx_dot_product} into a massive system of linear equations:
\begin{equation}
\label{eq:arx_matrix}
Y = \Phi \Theta_{\mathrm{ARX}} + E
\end{equation}
where $Y \in \mathbb{R}^{N \times 1}$ is the measurement vector, $E \in \mathbb{R}^{N \times 1}$ is the residual error vector, and $\Phi \in \mathbb{R}^{N \times 3}$ is the global regressor matrix constructed from the system telemetry:
\begin{equation}
\label{eq:regressor_matrix_full}
\Phi = \begin{bmatrix}
y_0 & i_1 & i_0 \\
y_1 & i_2 & i_1 \\
\vdots & \vdots & \vdots \\
y_{N-1} & i_N & i_{N-1}
\end{bmatrix}
\end{equation}

\subsubsection{The Closed-Form Normal Equation}
Because Equation \eqref{eq:arx_matrix} is fundamentally linear, the optimal parameter vector $\hat{\Theta}_{\mathrm{ARX}}$ that unconditionally minimizes the sum of squared residuals $J(\Theta_{\mathrm{ARX}}) = E^T E$ is obtained via analytical differentiation. Setting the gradient $\nabla_{\Theta} J$ to zero yields the foundational Normal Equation of ordinary least squares (OLS):
\begin{equation}
\label{eq:normal_equation}
\hat{\Theta}_{\mathrm{ARX}} = (\Phi^T \Phi)^{-1} \Phi^T Y
\end{equation}
This operation requires a single matrix inversion of the Gram matrix $(\Phi^T \Phi)$, which for a first-order ECM is merely a $3 \times 3$ matrix. This computational triviality is the primary reason ARX regression is utilized to rapidly initialize parameter bounds for more complex algorithms.

\subsubsection{Algebraic Transformation Back to Continuous Physical Parameters}
The vector $\hat{\Theta}_{\mathrm{ARX}}$ contains mathematical coefficients devoid of direct physical meaning. To recover the physical battery parameters $[R_0, R_1, C_1]$, an inverse algebraic mapping is required. By expanding the bilinear transform terms defining $a_1, b_0,$ and $b_1$ and substituting them into Equation \eqref{eq:theta_arx}, a system of algebraic equations is formed. Solving this system yields the exact physical parameters \cite{plett2015battery_v1}:

\begin{equation}
\label{eq:arx_to_r0}
R_0 = \frac{\theta_2 - \theta_3}{1 + \theta_1}
\end{equation}
\begin{equation}
\label{eq:arx_to_tau}
\tau_1 = R_1 C_1 = \frac{\Delta t}{2} \left( \frac{1 + \theta_1}{1 - \theta_1} \right)
\end{equation}
\begin{equation}
\label{eq:arx_to_r1}
R_1 = \frac{\theta_2 + \theta_3}{1 - \theta_1} - R_0
\end{equation}
With $\tau_1$ and $R_1$ calculated, the polarization capacitance is trivially found via $C_1 = \tau_1 / R_1$. This ARX methodology provides a mathematically guaranteed global minimum for the discrete system, completely eliminating the risk of optimization algorithms stalling in local minima, provided the measurement noise is strictly white.

\subsection{Nonlinear Least Squares (NLLS) Curve Fitting}
\label{subsec:nlls_curve_fitting}

While the ARX formulation is elegant for complete dynamic profiles, it struggles with highly noisy data due to its reliance on the recursive measurement $y_{k-1}$ within the regressor matrix $\Phi$, a phenomenon known as equation error bias. Furthermore, for specific relaxation phase analysis (where $I=0$), researchers often prefer to fit the multi-exponential decay curves directly in the time domain. 

The voltage relaxation of a Dual-Polarization (Second-Order RC) model following a current pulse is described by the nonlinear function:
\begin{equation}
\label{eq:nlls_relaxation}
V(t) = U_{\mathrm{oc}} - A_1 \exp\left(-\frac{t}{\tau_1}\right) - A_2 \exp\left(-\frac{t}{\tau_2}\right)
\end{equation}

Because the parameters $\tau_1$ and $\tau_2$ exist inside the arguments of the exponential functions, the model cannot be factored into a linear $\Phi \theta$ matrix form. Consequently, no closed-form analytical solution exists. The objective function $J(\theta)$ must be minimized utilizing iterative Nonlinear Least Squares (NLLS) numerical optimization \cite{aster2018parameter}.

\subsubsection{The Jacobian Matrix and the Gauss-Newton Algorithm}
Iterative optimization begins with an initial parameter guess $\theta_0$ and updates it across successive iterations $i$ such that $J(\theta_{i+1}) < J(\theta_i)$. The foundational algorithm for NLLS is the Gauss-Newton method, which utilizes a first-order Taylor series expansion to locally linearize the nonlinear residual function $e(\theta)$ around the current operating point $\theta_i$:
\begin{equation}
\label{eq:taylor_expansion}
E(\theta) \approx E(\theta_i) + J_i (\theta - \theta_i)
\end{equation}
where $J_i$ is the Jacobian matrix evaluated at $\theta_i$. The Jacobian is defined as the matrix of first-order partial derivatives of the residuals with respect to every parameter:
\begin{equation}
\label{eq:jacobian_def}
J_i = \left[ \frac{\partial e_k}{\partial \theta_m} \right] \in \mathbb{R}^{N \times P}
\end{equation}
where $N$ is the number of data samples and $P$ is the number of parameters being estimated (e.g., $P=5$ for $[U_{\mathrm{oc}}, A_1, \tau_1, A_2, \tau_2]$).

By substituting the local linearization (Equation \eqref{eq:taylor_expansion}) back into the least squares cost function and setting the gradient to zero, we derive the Gauss-Newton iterative parameter update step:
\begin{equation}
\label{eq:gauss_newton_update}
\theta_{i+1} = \theta_i - (J_i^T J_i)^{-1} J_i^T E(\theta_i)
\end{equation}
The matrix $(J_i^T J_i)$ serves as a computationally efficient approximation of the system's true Hessian matrix (the matrix of second derivatives). While Gauss-Newton exhibits extremely rapid quadratic convergence near the true global minimum, it is dangerously unstable if the initial guess $\theta_0$ is poor or if the matrix $(J_i^T J_i)$ becomes singular or ill-conditioned.

\subsubsection{The Levenberg-Marquardt (LM) Algorithm}
To address the instability of the pure Gauss-Newton method, the Levenberg-Marquardt (LM) algorithm is universally recognized as the industry standard for offline battery parameter curve fitting. The LM algorithm introduces a dynamic damping factor $\lambda$ to the update equation:
\begin{equation}
\label{eq:lm_update}
\theta_{i+1} = \theta_i - (J_i^T J_i + \lambda \operatorname{diag}(J_i^T J_i))^{-1} J_i^T E(\theta_i)
\end{equation}

The damping factor $\lambda$ acts as an algorithmic interpolator:
\begin{itemize}
    \item \textbf{When $\lambda$ is large:} The matrix is dominated by its diagonal, effectively transforming the update into a Gradient Descent (Steepest Descent) step. This is slow but mathematically guaranteed to move downward toward the minimum, rendering the algorithm highly robust to terrible initial guesses.
    \item \textbf{When $\lambda$ is small:} The $\lambda$ term vanishes, and the update reverts to the pure Gauss-Newton step (Equation \eqref{eq:gauss_newton_update}), providing rapid quadratic convergence in the final stages of the optimization.
\end{itemize}

During execution, if an update step successfully reduces the cost function $J(\theta)$, $\lambda$ is divided by a scaling factor to accelerate convergence. If an update step increases the cost function, the step is rejected, and $\lambda$ is multiplied by a scaling factor to force the algorithm into a more robust gradient descent trajectory. This hybrid architecture ensures that multi-exponential RC time constants can be fitted effectively even in the presence of severe experimental noise.

\subsection{Parameter Identifiability and Sensitivity Analysis}
\label{subsec:identifiability_sensitivity}

A foundational risk in offline regression is over-parameterization. While fitting a highly complex Third-Order RC model to a dataset might yield a visually perfect curve fit with a near-zero residual, the resulting mathematical parameters may be entirely unphysical or wildly unstable. This occurs when parameters are structurally unidentifiable or heavily correlated \cite{hu2012comparative}. Identifiability analysis mathematically guarantees that the dataset contains sufficient spectral richness to uniquely extract every parameter in the vector $\theta$.

\subsubsection{The Fisher Information Matrix (FIM)}
The fundamental tool for evaluating structural and practical identifiability during offline regression is the Fisher Information Matrix (FIM). In the context of Gaussian measurement noise with variance $\sigma^2$, the FIM, denoted as $\mathcal{I}(\theta)$, quantifies the amount of "information" the observable dataset $Y$ carries regarding the unknown parameters $\theta$. It is directly related to the Jacobian matrix defined earlier:
\begin{equation}
\label{eq:fisher_information}
\mathcal{I}(\theta) = \frac{1}{\sigma^2} (J^T J) = \frac{1}{\sigma^2} \sum_{k=1}^{N} \left( \nabla_\theta \hat{y}_k(\theta) \right) \left( \nabla_\theta \hat{y}_k(\theta) \right)^T
\end{equation}

For a parameter vector to be uniquely identifiable, the Fisher Information Matrix must be strictly full-rank (i.e., invertible). If the determinant of $\mathcal{I}(\theta)$ is zero (or dangerously close to zero, measured via the matrix condition number), the parameters are unidentifiable. 

In battery modeling, a singular FIM typically occurs when attempting to identify a Dual-Polarization model where the actual physical time constants $\tau_1$ and $\tau_2$ are nearly identical. The partial derivatives within the Jacobian become linearly dependent columns, causing the Gram matrix $(J^T J)$ to collapse. The LM algorithm will mathematically struggle to assign the overpotential, wildly oscillating $R_1$ and $R_2$ across iterations to satisfy the same macroscopic curve.

\subsubsection{The Cramer-Rao Lower Bound (CRLB)}
The Fisher Information Matrix establishes the absolute theoretical limit on the accuracy of any unbiased parameter estimator, formalized as the Cramer-Rao Lower Bound (CRLB). The covariance matrix of the estimated parameter vector $\hat{\theta}$ satisfies the inequality:
\begin{equation}
\label{eq:crlb}
\mathrm{Cov}(\hat{\theta}) \ge \mathcal{I}(\theta)^{-1}
\end{equation}

The diagonal elements of the inverse FIM provide the minimum achievable variance for each specific parameter. If the diagonal entry corresponding to the slow diffusion capacitance $C_2$ is phenomenally large, the regression algorithm mathematically proves that the experimental dataset (e.g., the HPPC pulse) was either not long enough or did not contain enough energy to confidently identify that parameter. Offline regression frameworks utilize the CRLB to generate 95\% confidence intervals for every extracted battery parameter, allowing engineers to discard unidentifiable parameters before loading them into the live BMS lookup tables.

\subsection{Tikhonov Regularization for Ill-Conditioned Datasets}
\label{subsec:tikhonov_regularization}

When the Fisher Information Matrix indicates severe ill-conditioning (a high condition number $\kappa(J^T J)$), the standard Ordinary Least Squares (OLS) or Gauss-Newton solutions will amplify measurement noise exponentially, resulting in enormous, unphysical parameter estimates (e.g., negative resistances or infinite capacitances). 

To stabilize the offline parameter extraction without resorting to a lower-order model, engineers apply Tikhonov Regularization (also known mathematically as Ridge Regression in the linear case). Regularization modifies the foundational objective function by adding a penalty term proportional to the magnitude of the parameter vector \cite{aster2018parameter}:
\begin{equation}
\label{eq:tikhonov_cost}
J_{\mathrm{reg}}(\theta) = \frac{1}{2} \| Y - \hat{Y}(\theta) \|_2^2 + \frac{\alpha}{2} \| \Gamma (\theta - \theta_{\mathrm{prior}}) \|_2^2
\end{equation}

Here, $\alpha$ is the scalar regularization parameter, $\Gamma$ is the Tikhonov matrix (often simply the identity matrix $I$), and $\theta_{\mathrm{prior}}$ represents an initial physical baseline guess for the parameters.

By penalizing massive deviations in the parameter vector, Tikhonov regularization mathematically forces the $(J^T J)$ matrix to become invertible. The regularized linear least squares normal equation becomes:
\begin{equation}
\label{eq:tikhonov_solution}
\hat{\Theta}_{\mathrm{reg}} = (\Phi^T \Phi + \alpha \Gamma^T \Gamma)^{-1} (\Phi^T Y + \alpha \Gamma^T \Gamma \theta_{\mathrm{prior}})
\end{equation}

The tuning of $\alpha$ is typically achieved through L-curve analysis or Generalized Cross-Validation (GCV) during the offline processing phase. While regularization introduces a slight deterministic bias to the identified parameters, it drastically reduces their variance, ensuring that the offline extraction pipeline generates physically realistic, stable ECM bounds suitable for subsequent compilation into the vehicle's embedded architecture.



\section{Least Squares Formulations}
\label{sec:least_squares_formulations}

The foundational algorithm underpinning almost all offline parameter extraction in battery engineering is the Least Squares (LS) estimator. Originally formalized by Gauss and Legendre, the least squares method provides a mathematically rigorous framework for solving overdetermined systems—systems where the number of experimental observations vastly exceeds the number of unknown parameters. 

In the context of lithium-ion battery characterization (such as processing the thousands of discrete voltage and current samples generated during an HPPC test), the LS formulation seeks the optimal parameter vector $\theta \in \mathbb{R}^p$ that minimizes the squared discrepancies between the experimental terminal voltage measurements $Y \in \mathbb{R}^N$ and the predictions of the mathematical plant model (e.g., the discretized Equivalent Circuit Models derived in Chapter 2).

Depending on the statistical distribution of the measurement noise generated by the Battery Management System's (BMS) Analog Front-End (AFE), the least squares objective function must be structurally adapted. This section rigorously derives the Ordinary Least Squares (OLS) and Weighted Least Squares (WLS) estimators, explicitly analyzing their statistical optimality, inherent biases, and practical applications in battery system identification.

\subsection{Ordinary Least Squares (OLS)}
\label{subsec:ordinary_least_squares}

The Ordinary Least Squares (OLS) method is the most ubiquitous parameter estimation technique due to its computational efficiency and the existence of a globally optimal, closed-form analytical solution. It is applied when the battery model can be formulated as a system of equations that is strictly linear with respect to the parameter vector $\theta$. 

As established in Section \ref{subsec:arx_formulation}, continuous-time ECMs can be discretized into an Auto-Regressive Exogenous (ARX) format, allowing the entire dataset to be represented by the discrete linear measurement model:
\begin{equation}
\label{eq:ols_linear_model}
Y = \Phi \theta + \mathcal{E}
\end{equation}
where:
\begin{itemize}
    \item $Y = [y_1, y_2, \dots, y_N]^T$ is the observation vector composed of $N$ discrete terminal voltage measurements.
    \item $\Phi \in \mathbb{R}^{N \times p}$ is the regressor matrix (or design matrix), containing historical sequences of inputs (current $I$) and outputs (voltage $V$).
    \item $\theta = [\theta_1, \theta_2, \dots, \theta_p]^T$ is the unknown parameter vector to be identified.
    \item $\mathcal{E} = [\varepsilon_1, \varepsilon_2, \dots, \varepsilon_N]^T$ represents the unobservable, true stochastic noise perturbing the physical system.
\end{itemize}

\subsubsection{Derivation of the OLS Estimator}
The OLS algorithm does not attempt to solve $Y = \Phi \theta$ algebraically, as the presence of the random noise vector $\mathcal{E}$ guarantees that no exact solution exists for $N > p$. Instead, it defines a deterministic residual vector $E(\hat{\theta}) = Y - \Phi \hat{\theta}$, representing the error between the measured data and the model's prediction based on a candidate parameter estimate $\hat{\theta}$.

The objective function $J_{\mathrm{OLS}}(\hat{\theta})$ is defined as the scalar sum of squared residuals:
\begin{equation}
\label{eq:ols_cost_function}
J_{\mathrm{OLS}}(\hat{\theta}) = \frac{1}{2} \sum_{k=1}^N e_k^2 = \frac{1}{2} E(\hat{\theta})^T E(\hat{\theta}) = \frac{1}{2} (Y - \Phi \hat{\theta})^T (Y - \Phi \hat{\theta})
\end{equation}

Expanding the vector transpose yields:
\begin{equation}
\label{eq:ols_cost_expanded}
J_{\mathrm{OLS}}(\hat{\theta}) = \frac{1}{2} \left( Y^T Y - Y^T \Phi \hat{\theta} - \hat{\theta}^T \Phi^T Y + \hat{\theta}^T \Phi^T \Phi \hat{\theta} \right)
\end{equation}
Recognizing that the scalar inner product $Y^T \Phi \hat{\theta}$ is equal to its transpose $\hat{\theta}^T \Phi^T Y$, the expression simplifies to:
\begin{equation}
\label{eq:ols_cost_simplified}
J_{\mathrm{OLS}}(\hat{\theta}) = \frac{1}{2} Y^T Y - \hat{\theta}^T \Phi^T Y + \frac{1}{2} \hat{\theta}^T \Phi^T \Phi \hat{\theta}
\end{equation}

To find the global minimum, we compute the gradient of the objective function with respect to the parameter vector $\hat{\theta}$ and equate it to the zero vector:
\begin{equation}
\label{eq:ols_gradient}
\nabla_{\hat{\theta}} J_{\mathrm{OLS}} = -\Phi^T Y + \Phi^T \Phi \hat{\theta} = \mathbf{0}
\end{equation}

Rearranging this result yields the classical Normal Equations:
\begin{equation}
\label{eq:ols_normal_equations_derivation}
(\Phi^T \Phi) \hat{\theta} = \Phi^T Y
\end{equation}

Provided that the regressor matrix $\Phi$ has full column rank (meaning the input current contains sufficient spectral richness to guarantee that the columns of $\Phi$ are linearly independent), the Gram matrix $(\Phi^T \Phi)$ is positive definite and invertible. Left-multiplying by this inverse yields the definitive OLS estimator:
\begin{equation}
\label{eq:ols_estimator}
\hat{\theta}_{\mathrm{OLS}} = (\Phi^T \Phi)^{-1} \Phi^T Y
\end{equation}

The term $(\Phi^T \Phi)^{-1} \Phi^T$ is often referred to as the Moore-Penrose pseudoinverse $\Phi^+$. It provides the unique, mathematically guaranteed global minimum for the defined residual surface.

\subsubsection{Statistical Properties and the Gauss-Markov Theorem}
While Equation \eqref{eq:ols_estimator} provides an algebraic solution, its validity as a physical parameter identification tool depends strictly on the statistical properties of the noise $\mathcal{E}$. The Gauss-Markov theorem states that the OLS estimator $\hat{\theta}_{\mathrm{OLS}}$ is the Best Linear Unbiased Estimator (BLUE) if and only if the underlying stochastic noise process satisfies three rigid conditions:
\begin{enumerate}
    \item \textbf{Strict Exogeneity:} The expected value of the noise is zero, $\mathbb{E}[\mathcal{E}] = \mathbf{0}$, and the noise is completely uncorrelated with the regressor matrix, $\mathbb{E}[\Phi^T \mathcal{E}] = \mathbf{0}$.
    \item \textbf{Homoscedasticity:} The variance of the noise is constant across all measurements. $\mathrm{Var}(\varepsilon_k) = \sigma^2$ for all $k$.
    \item \textbf{No Autocorrelation:} The noise at time step $k$ is statistically independent of the noise at any other time step $j$. The noise covariance matrix is purely diagonal: $\mathbb{E}[\mathcal{E} \mathcal{E}^T] = \sigma^2 I_N$, where $I_N$ is the identity matrix.
\end{enumerate}

If these conditions are met, we can rigorously prove that the OLS estimator is unbiased. Substituting the true system $Y = \Phi \theta + \mathcal{E}$ into the estimator yields:
\begin{equation}
\label{eq:ols_unbiased_proof}
\begin{aligned}
\hat{\theta}_{\mathrm{OLS}} &= (\Phi^T \Phi)^{-1} \Phi^T (\Phi \theta + \mathcal{E}) \\
&= (\Phi^T \Phi)^{-1} \Phi^T \Phi \theta + (\Phi^T \Phi)^{-1} \Phi^T \mathcal{E} \\
&= \theta + (\Phi^T \Phi)^{-1} \Phi^T \mathcal{E}
\end{aligned}
\end{equation}
Taking the mathematical expectation:
\begin{equation}
\label{eq:ols_expectation}
\mathbb{E}[\hat{\theta}_{\mathrm{OLS}}] = \theta + (\Phi^T \Phi)^{-1} \mathbb{E}[\Phi^T \mathcal{E}] = \theta + \mathbf{0} = \theta
\end{equation}

Furthermore, the covariance matrix of the identified parameters---which establishes the confidence intervals for the identified resistance and capacitance values---is evaluated as:
\begin{equation}
\label{eq:ols_covariance}
\begin{aligned}
\mathrm{Cov}(\hat{\theta}_{\mathrm{OLS}}) &= \mathbb{E} \left[ (\hat{\theta}_{\mathrm{OLS}} - \theta)(\hat{\theta}_{\mathrm{OLS}} - \theta)^T \right] \\
&= \mathbb{E} \left[ ((\Phi^T \Phi)^{-1} \Phi^T \mathcal{E})((\Phi^T \Phi)^{-1} \Phi^T \mathcal{E})^T \right] \\
&= (\Phi^T \Phi)^{-1} \Phi^T \mathbb{E}[\mathcal{E} \mathcal{E}^T] \Phi (\Phi^T \Phi)^{-1}
\end{aligned}
\end{equation}
Substituting the homoscedasticity assumption $\mathbb{E}[\mathcal{E} \mathcal{E}^T] = \sigma^2 I_N$:
\begin{equation}
\label{eq:ols_covariance_final}
\mathrm{Cov}(\hat{\theta}_{\mathrm{OLS}}) = \sigma^2 (\Phi^T \Phi)^{-1}
\end{equation}

The diagonal elements of $\sigma^2 (\Phi^T \Phi)^{-1}$ provide the exact variance for each individual parameter $\theta_i$. If the matrix $(\Phi^T \Phi)$ is ill-conditioned (indicating poor current excitation), its inverse will contain massive values, mathematically demonstrating that the extracted battery parameters carry extreme uncertainty and should be rejected.

\subsubsection{Equation Error Bias in Battery ARX Models}
A fundamental limitation of utilizing OLS on discrete battery models is the violation of the strict exogeneity condition. When a continuous-time ECM is discretized into an ARX format (Equation \eqref{eq:arx_difference}), the regressor vector $\phi_k = [y_{k-1}, i_k, i_{k-1}]^T$ contains the previous voltage measurement $y_{k-1}$. 

In physical reality, the measurement $y_{k-1}$ is itself corrupted by sensor noise $v_{k-1}$. Therefore, the regressor matrix $\Phi$ contains noise that is mathematically correlated with the equation error $\mathcal{E}$. Because $\mathbb{E}[\Phi^T \mathcal{E}] \neq \mathbf{0}$, the OLS estimator becomes fundamentally biased \cite{ljung1999system}. This is known as Equation Error Bias. As measurement noise increases, OLS systematically underestimates the dynamic time constants ($\tau$) and overestimates the instantaneous ohmic resistance ($R_0$). Advanced techniques, such as Instrumental Variables (IV) or the nonlinear least squares methods discussed in Section \ref{subsec:nlls_curve_fitting}, are required to eliminate this asymptotic bias.

\subsection{Weighted Least Squares (WLS)}
\label{subsec:weighted_least_squares}

The Ordinary Least Squares framework relies on the rigid assumption of homoscedasticity---that the variance of the sensor noise $\sigma^2$ is perfectly constant across the entire dataset. In battery parameter identification, this assumption is demonstrably false. 

Consider an HPPC test profile. During the zero-current relaxation phases, the voltage sensor noise is dictated solely by the thermal noise floor of the ADC. However, during a 5C high-current discharge pulse, the massive current induces significant temperature gradients, dynamic EMI from the cycler cables, and quantization scaling errors. The variance of the terminal voltage residual during the dynamic pulse is inherently orders of magnitude larger than the variance during the resting phase. 

Applying pure OLS to this heteroscedastic dataset forces the algorithm to weight a noisy measurement during a transient pulse equally with a pristine measurement during a relaxation phase. The resulting parameter vector will be skewed to fit the noisy transients at the expense of accurate steady-state polarization tracking. Weighted Least Squares (WLS) mathematically resolves this by dynamically prioritizing high-confidence measurements and discounting noisy data \cite{aster2018parameter}.

\subsubsection{Derivation of the WLS Estimator}
To compensate for varying noise reliability, we introduce an $N \times N$ symmetric, positive-definite weight matrix $W$. The objective function is redefined to penalize the residuals proportionally to their assigned weights:
\begin{equation}
\label{eq:wls_cost_function}
J_{\mathrm{WLS}}(\hat{\theta}) = \frac{1}{2} E(\hat{\theta})^T W E(\hat{\theta}) = \frac{1}{2} (Y - \Phi \hat{\theta})^T W (Y - \Phi \hat{\theta})
\end{equation}

Expanding this weighted quadratic form yields:
\begin{equation}
\label{eq:wls_cost_expanded}
J_{\mathrm{WLS}}(\hat{\theta}) = \frac{1}{2} \left( Y^T W Y - Y^T W \Phi \hat{\theta} - \hat{\theta}^T \Phi^T W Y + \hat{\theta}^T \Phi^T W \Phi \hat{\theta} \right)
\end{equation}
Because $W$ is symmetric ($W = W^T$), the cross-terms are identical. Simplifying and taking the gradient with respect to $\hat{\theta}$:
\begin{equation}
\label{eq:wls_gradient}
\nabla_{\hat{\theta}} J_{\mathrm{WLS}} = -\Phi^T W Y + \Phi^T W \Phi \hat{\theta} = \mathbf{0}
\end{equation}

Rearranging this yields the modified Normal Equations for Weighted Least Squares:
\begin{equation}
\label{eq:wls_estimator}
\hat{\theta}_{\mathrm{WLS}} = (\Phi^T W \Phi)^{-1} \Phi^T W Y
\end{equation}

The WLS estimator fundamentally alters the geometry of the residual space, stretching and compressing the axes based on the matrix $W$ to ensure that parameters are fitted preferentially to the most reliable data points.

\subsubsection{Optimal Selection of the Weight Matrix ($W$)}
The mathematical efficacy of WLS depends entirely on the correct formulation of the weight matrix $W$. According to the generalized Gauss-Markov theorem, the theoretically optimal weight matrix that minimizes the parameter covariance (maximizing estimator confidence) is strictly the inverse of the measurement noise covariance matrix $\Sigma$:
\begin{equation}
\label{eq:wls_optimal_weight}
W_{\mathrm{optimal}} = \Sigma^{-1} = \left( \mathbb{E}[\mathcal{E}\mathcal{E}^T] \right)^{-1}
\end{equation}

If the measurement noise is heteroscedastic but uncorrelated (i.e., noise at step $k$ does not depend on noise at step $k-1$), the matrix $\Sigma$ is diagonal, containing the individual variances $\sigma_k^2$ for each discrete measurement:
\begin{equation}
\label{eq:wls_diagonal_sigma}
\Sigma = \operatorname{diag}(\sigma_1^2, \sigma_2^2, \dots, \sigma_N^2)
\end{equation}
The optimal weight matrix $W$ is therefore also diagonal, containing the reciprocal variances:
\begin{equation}
\label{eq:wls_diagonal_weight}
W = \operatorname{diag}\left(\frac{1}{\sigma_1^2}, \frac{1}{\sigma_2^2}, \dots, \frac{1}{\sigma_N^2}\right)
\end{equation}

Equation \eqref{eq:wls_diagonal_weight} mathematically formalizes the WLS philosophy: measurements with high variance $\sigma_k^2$ (high noise) receive a proportionally low weight $w_{k,k}$, minimizing their influence on the parameter identification.

\subsubsection{Practical Implementation in BMS Parameter Extraction}
In real-world battery characterization, the true, instantaneous variance $\sigma_k^2$ is inherently unobservable. Engineers must approximate the weight matrix $W$ using empirical heuristics based on sensor metrology and operational domains:

\begin{enumerate}
    \item \textbf{Sensor-Fused Weighting:} If terminal voltage noise is heavily dependent on the applied current magnitude (due to electromagnetic coupling with the cycler leads), the variance can be modeled linearly: $\sigma_k^2 \approx \sigma_{\mathrm{ADC}}^2 + c |I_k|$, where $c$ is an empirical scaling factor. The diagonal weight matrix is populated accordingly.
    \item \textbf{Phase-Based Weighting:} During offline extraction of Dual-Polarization parameters, engineers often apply binary weights. A high scalar weight (e.g., $w=10$) is assigned to indices corresponding to zero-current relaxation phases to aggressively anchor the slow diffusion parameters ($R_2, C_2$). A lower weight (e.g., $w=1$) is assigned to the dynamic pulse phases, which are structurally dominated by the instantaneous ohmic resistance $R_0$, which is less sensitive to precise curve-fitting.
    \item \textbf{Generalized Least Squares (GLS) for Autocorrelation:} If low-pass analog filters are present in the measurement circuitry, the noise becomes temporally correlated (autocorrelated), meaning $\Sigma$ is no longer strictly diagonal. In this scenario, applying WLS with the full, non-diagonal precision matrix $\Sigma^{-1}$ yields the Generalized Least Squares (GLS) estimator, which performs complex pre-whitening on the dataset before identifying the parameters \cite{plett2015battery_v1}.
\end{enumerate}

\section{Heuristic Optimization Algorithms}
\label{sec:heuristic_optimization}

The gradient-based offline identification methods detailed in Section \ref{sec:curve_fitting_regression}, such as the Gauss-Newton and Levenberg-Marquardt (LM) algorithms, exhibit rapid, quadratic convergence when initialized near the true parameter values. However, their reliance on the Jacobian matrix renders them highly susceptible to failure when navigating the complex error surfaces typical of advanced battery models. 

The objective function $J(\theta)$ of a multi-order equivalent circuit model (e.g., a Second-Order Dual-Polarization ECM) or a reduced-order electrochemical model (e.g., the Single Particle Model) is inherently non-convex. The error surface is characterized by localized valleys, flat plateaus (where gradient information vanishes), and steep non-differentiable boundaries. If a gradient-based algorithm is initialized with a poor a priori parameter guess, it will deterministically converge to the nearest local minimum, yielding a mathematically valid but physically erroneous parameter set \cite{fotouhi2016review}.

To circumvent the limitations of local derivatives, researchers increasingly deploy heuristic and meta-heuristic optimization algorithms for offline battery parameter extraction. These methods are stochastic, derivative-free, population-based search strategies inspired by natural phenomena. By evaluating the cost function at multiple dispersed points simultaneously, they map the global topology of the error surface, dramatically increasing the probability of locating the true global minimum. This section formally derives the two most prominent heuristic algorithms applied to battery system identification: Genetic Algorithms (GA) and Particle Swarm Optimization (PSO).

\subsection{Genetic Algorithms (GA)}
\label{subsec:genetic_algorithms}

Genetic Algorithms (GA), fundamentally introduced by Holland \cite{holland1992adaptation}, are stochastic global search methods rooted in the principles of Darwinian evolution and natural genetics. The algorithm operates on a population of candidate parameter vectors, iteratively applying biologically inspired operators—selection, crossover, and mutation—to evolve the population toward optimal regions of the search space.

\subsubsection{Formulation and Encoding for Battery Systems}
In standard GA theory, variables are often encoded as binary strings (chromosomes). However, battery parameters such as ohmic resistance ($R_0$) and polarization capacitance ($C_1$) exist in a continuous real-number domain. Binary encoding discretizes this continuous space, introducing quantization error and requiring excessive string lengths to achieve the micro-ohm precision necessary for modern lithium-ion cells. Consequently, battery parameter identification universally employs Real-Coded Genetic Algorithms (RCGA).

Let the parameter vector to be identified be denoted as an individual "chromosome," defined as:
\begin{equation}
\label{eq:ga_chromosome}
\theta_i = [\theta_{i,1}, \theta_{i,2}, \dots, \theta_{i,p}]^T, \quad i = 1, 2, \dots, N_{\mathrm{pop}}
\end{equation}
where $p$ is the number of unknown parameters (the genes) and $N_{\mathrm{pop}}$ is the total number of individuals in the population.

The algorithm initializes by stochastically generating a population within strictly defined physical boundaries. For battery parameters, these boundaries are critical to enforce physical validity (e.g., resistances and capacitances must be strictly positive). The initial population is generated via a uniform random distribution:
\begin{equation}
\label{eq:ga_initialization}
\theta_{i,j}^{(0)} = \theta_{j}^{\min} + \mathcal{U}(0,1) \left( \theta_{j}^{\max} - \theta_{j}^{\min} \right)
\end{equation}
where $\mathcal{U}(0,1)$ is a uniformly distributed random number between 0 and 1, and $[\theta_{j}^{\min}, \theta_{j}^{\max}]$ represent the predefined engineering bounds for the $j$-th parameter.

\subsubsection{Fitness Function Definition}
The driving mechanism of the GA is the fitness function, $\mathcal{F}(\theta)$, which quantifies the suitability of each individual. While regression algorithms minimize a cost function $J(\theta)$ (typically the Sum of Squared Errors, SSE), genetic algorithms are historically formulated to maximize fitness. Therefore, the battery tracking error must be inverted. A standard fitness formulation includes a small regularization constant $\epsilon$ to prevent division by zero in the event of a perfect fit:
\begin{equation}
\label{eq:ga_fitness}
\mathcal{F}(\theta_i) = \frac{1}{J(\theta_i) + \epsilon} = \frac{1}{\frac{1}{N}\sum_{k=1}^N \left( y_k - \hat{y}_k(\theta_i) \right)^2 + \epsilon}
\end{equation}
Individuals with lower residual tracking errors yield higher fitness values, increasing their probability of propagating their genetic material to the subsequent generation.

\subsubsection{Evolutionary Operators}
The transition from generation $g$ to $g+1$ is governed by three sequential operators.

\textbf{1. Selection:} This operator dictates which chromosomes are chosen to reproduce. To maintain evolutionary pressure while preserving genetic diversity, stochastic selection mechanisms are employed. A common formulation in battery parameter extraction is Roulette Wheel Selection (Fitness Proportionate Selection), where the probability $P_i$ of selecting individual $\theta_i$ is explicitly proportional to its normalized fitness:
\begin{equation}
\label{eq:ga_selection}
P_i = \frac{\mathcal{F}(\theta_i)}{\sum_{j=1}^{N_{\mathrm{pop}}} \mathcal{F}(\theta_j)}
\end{equation}
To prevent premature convergence (where a single super-individual dominates the population and halts global exploration), Tournament Selection is often preferred. In this variant, $k$ individuals are selected at random, and the individual with the highest fitness among the $k$ selected becomes a parent.

\textbf{2. Crossover (Recombination):} Crossover acts as the primary exploitation mechanism, combining the parameters of two parent vectors ($\theta_A, \theta_B$) to produce offspring. For Real-Coded GAs identifying continuous battery parameters, Arithmetic Crossover is standard. Two new offspring, $\theta_{C}$ and $\theta_{D}$, are generated via a linear combination of the parents using a random weighting factor $\beta \in [0,1]$:
\begin{equation}
\label{eq:ga_crossover_1}
\theta_{C} = \beta \theta_A + (1 - \beta) \theta_B
\end{equation}
\begin{equation}
\label{eq:ga_crossover_2}
\theta_{D} = (1 - \beta) \theta_A + \beta \theta_B
\end{equation}
This operator is applied with a defined crossover probability, $p_c$ (typically $0.7 \le p_c \le 0.9$). 

\textbf{3. Mutation:} Mutation serves as the primary exploration operator, injecting spontaneous genetic diversity into the population to dislodge the algorithm from local minima. It alters individual parameters with a low mutation probability, $p_m$ (typically $0.01 \le p_m \le 0.05$). For continuous ECM variables, Non-Uniform Gaussian Mutation is frequently utilized. A selected parameter $\theta_{i,j}$ is perturbed by a Gaussian distribution whose variance systematically decays as the generation number $g$ increases:
\begin{equation}
\label{eq:ga_mutation}
\theta_{i,j}^{(g+1)} = \theta_{i,j}^{(g)} + \Delta(g, \theta_{j}^{\max} - \theta_{i,j}^{(g)})
\end{equation}
The function $\Delta(g, y)$ returns a random value in the range $[0, y]$ such that the probability of returning a number close to zero increases as the algorithm nears the maximum generation limit $G_{\max}$. This ensures broad exploration during early iterations and fine-tuned exploitation during the terminal phases of the parameter search.

\subsubsection{Application and Limitations in Battery Systems}
GAs are remarkably robust at identifying the complete parameter sets of Dual-Polarization ECMs directly from highly dynamic, non-resting drive cycle datasets (e.g., the Urban Dynamometer Driving Schedule, UDDS) where gradient methods instantly fail \cite{rahmoun2012modeling}. 

However, the primary limitation of GA for offline battery identification is its extreme computational overhead. Simulating the dynamic voltage response of the battery model $\hat{y}_k(\theta_i)$ for every individual in a large population over thousands of generations requires massive, repeated integrations of the state-space ODEs. While suitable for offline server-side processing, GAs lack the mathematical elegance and convergence speed necessary to be adapted for online or pseudo-real-time identification.

\subsection{Particle Swarm Optimization (PSO)}
\label{subsec:particle_swarm_optimization}

Particle Swarm Optimization (PSO) is a stochastic, population-based optimization technique proposed by Kennedy and Eberhart \cite{kennedy1995particle}. Unlike the competitive evolutionary mechanics of GA, PSO is rooted in cooperative swarm intelligence, mimicking the sociological behavior of bird flocking or fish schooling. 

Because PSO natively operates in continuous real-number vector spaces and relies on simple algebraic velocity updates rather than complex genetic permutations, it generally exhibits significantly faster convergence rates than GA for continuous battery parameter identification tasks, establishing it as the preferred meta-heuristic in recent electrochemical literature.

\subsubsection{Standard PSO Dynamics}
In the PSO framework, the population is termed a "swarm," and each candidate parameter vector is a "particle." Each particle $i$ navigates the $p$-dimensional battery parameter space. The state of a particle is defined by two vectors: its current position $x_i(k) \in \mathbb{R}^p$ (analogous to the parameter vector $\theta_i$) and its velocity $v_i(k) \in \mathbb{R}^p$, where $k$ is the current iteration step.

The movement of each particle is influenced by its own historical success and the collective success of the entire swarm. Every particle retains a memory of the best parameter configuration it has personally discovered so far, termed its personal best ($p_{\mathrm{best}, i}$). Simultaneously, the swarm communicates to identify the single global best configuration discovered by any particle, termed the global best ($g_{\mathrm{best}}$).

The core algorithm dictates that at each iteration $k$, the velocity and position of every particle are updated according to the following linear kinematic equations:
\begin{equation}
\label{eq:pso_velocity}
v_i(k+1) = w v_i(k) + c_1 r_1 \left( p_{\mathrm{best}, i} - x_i(k) \right) + c_2 r_2 \left( g_{\mathrm{best}} - x_i(k) \right)
\end{equation}
\begin{equation}
\label{eq:pso_position}
x_i(k+1) = x_i(k) + v_i(k+1)
\end{equation}

Equation \eqref{eq:pso_velocity} is mathematically divided into three distinct operational components:
\begin{enumerate}
    \item \textbf{Inertial Component ($w v_i(k)$):} Dictates the particle's tendency to continue in its current trajectory, preventing abrupt directional changes and promoting global exploration. The inertia weight $w$ is the primary tuning parameter.
    \item \textbf{Cognitive Component ($c_1 r_1 (p_{\mathrm{best}, i} - x_i(k))$):} Represents the particle's individual memory. The cognitive coefficient $c_1$ scales the particle's attraction toward its own historical success. $r_1 \sim \mathcal{U}(0,1)$ is a stochastic multiplier.
    \item \textbf{Social Component ($c_2 r_2 (g_{\mathrm{best}} - x_i(k))$):} Represents the swarm's collective knowledge. The social coefficient $c_2$ scales the attraction toward the global optimum found by the swarm. $r_2 \sim \mathcal{U}(0,1)$ is an independent stochastic multiplier.
\end{enumerate}

\subsubsection{Algorithmic Tuning for ECM Parameter Extraction}
The stability and convergence of the PSO algorithm depend heavily on the selection of $w$, $c_1$, and $c_2$. In the context of identifying multi-time-constant battery models, a static inertia weight $w$ frequently leads to suboptimal performance. If $w$ is too high, the swarm refuses to converge and oscillates wildly across the parameter bounds; if $w$ is too low, the swarm collapses prematurely into local minima.

To optimize battery ECM identification, modern implementations utilize a Time-Varying Inertia Weight (TVIW). The weight is linearly decremented from an initial maximum ($w_{\max}$) to a terminal minimum ($w_{\min}$) over the total number of maximum iterations ($K_{\max}$):
\begin{equation}
\label{eq:pso_tviw}
w(k) = w_{\max} - \left( \frac{w_{\max} - w_{\min}}{K_{\max}} \right) k
\end{equation}
Typically, $w_{\max} = 0.9$ and $w_{\min} = 0.4$. This structural adjustment ensures that the swarm executes wide, global exploration during the initial search phase to locate the correct general basin of attraction (e.g., roughly identifying the correct magnitude of the slow diffusion time constant $\tau_2$), and smoothly transitions into fine-tuned, localized exploitation during the final iterations to exactly pinpoint the parameter values.

\subsubsection{Constriction Factor Formulation}
To mathematically guarantee convergence without relying on arbitrary velocity clamping techniques (which artificially restrict the rate of change of parameters like $R_0$), advanced battery identification frameworks utilize the Constriction Factor PSO approach introduced by Clerc and Kennedy \cite{clerc2002particle}. 

By analyzing the eigenvalues of the dynamic system representing the particle updates, the standard velocity equation is modified to ensure the particle trajectories remain mathematically bounded:
\begin{equation}
\label{eq:pso_constriction_vel}
v_i(k+1) = \chi \left[ v_i(k) + c_1 r_1 \left( p_{\mathrm{best}, i} - x_i(k) \right) + c_2 r_2 \left( g_{\mathrm{best}} - x_i(k) \right) \right]
\end{equation}
where $\chi$ is the analytical constriction factor:
\begin{equation}
\label{eq:pso_constriction_factor}
\chi = \frac{2}{\left| 2 - \phi - \sqrt{\phi^2 - 4\phi} \right|}, \quad \text{with } \phi = c_1 + c_2, \quad \phi > 4
\end{equation}
Setting $c_1 = c_2 = 2.05$ yields $\phi = 4.1$, resulting in $\chi \approx 0.7298$. Deploying this exact mathematical configuration eliminates the need for the heuristic tuning of $w$, resulting in highly stable and rapid offline identification of ECM parameters even under complex drive-cycle current excitations.

\subsubsection{Handling Physical Constraints}
When the PSO algorithm updates the position vector $x_i(k+1)$, the stochastic nature of the velocity equation may push a particle outside the physically permissible boundaries of the battery parameters (e.g., forcing a negative resistance or an impossibly large capacitance). 

If a particle breaches a boundary, the physical battery simulation $\hat{y}_k(x_i)$ will become numerically unstable or physically meaningless. To address this, the algorithm employs strict boundary handling operators. The "Absorbing Wall" condition is standard in battery parameter extraction: if a particle dimension $x_{i,j}$ exceeds $\theta_{j}^{\max}$, its position is clamped to the boundary ($x_{i,j} = \theta_{j}^{\max}$), and its corresponding velocity component is forced to zero ($v_{i,j} = 0$), halting further excursion out of bounds while allowing other parameter dimensions to continue evolving.

\section{Summary}
\label{sec:summary_ch4}

This chapter provided a rigorous mathematical examination of the offline parameter identification methodologies essential for parameterizing modern battery models. The transition from continuous-time physical systems to computable discrete-time domains was established through the Auto-Regressive Exogenous (ARX) formulation, enabling the direct, non-iterative identification of linear baseline parameters using the analytical Ordinary Least Squares (OLS) estimator. The severe limitations of OLS regarding equation error bias and heteroscedastic noise were addressed through the rigorous statistical formulations of Weighted Least Squares (WLS).

When analytical formulations break down—specifically when confronting the multi-exponential nonlinearities inherent in dual-polarization voltage relaxation—the chapter demonstrated the necessity of numerical optimization. The mathematical derivations of the Gauss-Newton and Levenberg-Marquardt algorithms were detailed, highlighting the reliance on the Jacobian matrix and the consequent vulnerability to divergent initial conditions and singular Fisher Information Matrices. 

To overcome the failure modes of gradient-based techniques on non-convex, multidimensional error surfaces, the chapter concluded with a deep analytical exploration of heuristic global optimizers. The real-coded operators defining Genetic Algorithms (GA) were derived, alongside the kinematic swarming equations driving Particle Swarm Optimization (PSO). By integrating advanced constraint handling and analytical constriction factors, these meta-heuristic algorithms provide a highly robust, albeit computationally intensive, pathway to extracting true global parameter vectors $\theta$. Armed with these baseline offline models, the report will now transition in Chapter 5 to the online adaptive filtering techniques required to dynamically track these parameters as they drift in real-time embedded environments.
